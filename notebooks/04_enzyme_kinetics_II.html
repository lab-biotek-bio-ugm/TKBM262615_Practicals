L04 — Enzyme Kinetics II

Course: TBM263214 Komputasi Biologi (Computational Biology) · Week 4 · CPMK2

Companion notebook for scripts/04_enzyme_kinetics_II.py, based on the course lecture note 04-enzyme-kinetics-2-en.md.

Simulates competitive and non-competitive inhibition, then the Hill function — in its activating (“switch ON”) and repressing (“switch OFF”) forms — as a model of allosteric, cooperative regulation, and fits it to noisy data.

Learning Objectives

After this notebook, you should be able to: 1. Distinguish competitive from non-competitive inhibition by their effect on the apparent \(K_M\) and \(V_{max}\). (CPMK2) 2. Model allosteric, cooperative regulation with the Hill equation. (CPMK2) 3. Write the Hill activation and repression functions, and relate the Hill coefficient \(n\) to cooperativity. (CPMK2) 4. Explain sigmoidal kinetics as a “soft switch”, and how increasing \(n\) sharpens the transition. (CPMK2) 5. Fit a Hill function to noisy data and judge from the confidence interval on \(n\) whether cooperativity is supported. (CPMK2)

# Setup — Colab already ships numpy, scipy, and matplotlib, so no pip install is needed.
import numpy as np
import matplotlib.pyplot as plt

Key Concepts

  • Competitive inhibition: inhibitor \(I\) competes with substrate for the active site — it raises the apparent \(K_M\) but leaves \(V_{max}\) unchanged (enough substrate can still outcompete the inhibitor).
  • Non-competitive inhibition: \(I\) binds a separate site and lowers the apparent \(V_{max}\), while \(K_M\) is unchanged (no amount of substrate reverses it).
  • Cooperativity / allosteric regulation: binding of one ligand changes the enzyme’s affinity for the next — captured phenomenologically by the Hill equation with Hill coefficient \(n\) (\(n>1\): positive cooperativity).
  • Fitting: in practice \(n\) is fitted to \(v([S])\) data (scipy.optimize.curve_fit). Report its confidence interval, and compare against the \(n=1\) (Michaelis-Menten) fit before claiming cooperativity.
  • Hill function as a “soft switch”: an activating Hill function turns a response ON as \([S]\) rises; a repressing Hill function turns it OFF. Both are sigmoidal, and the transition sharpens toward a step function as \(n\) increases.

Key Equations

  • Competitive inhibition: \(\displaystyle v = \frac{V_{max}[S]}{K_M(1+[I]/K_i) + [S]}\)

  • Non-competitive inhibition: \(\displaystyle v = \frac{V_{max}}{1+[I]/K_i} \cdot \frac{[S]}{K_M + [S]}\)

  • Hill activation (switch ON): \(\displaystyle v = \frac{V_{max}[S]^n}{K^n + [S]^n}\)

  • Hill repression (switch OFF): \(\displaystyle v = \frac{V_{max} K^n}{K^n + [S]^n}\)

Vmax, KM, Ki = 10.0, 5.0, 2.0
S = np.linspace(0, 50, 400)

# Competitive inhibition: KM_app rises, Vmax stays fixed
def v_competitive(S, I):
    KM_app = KM * (1 + I / Ki)
    return Vmax * S / (KM_app + S)

# Non-competitive inhibition: Vmax_app falls, KM stays fixed
def v_noncompetitive(S, I):
    Vmax_app = Vmax / (1 + I / Ki)
    return Vmax_app * S / (KM + S)

I_values = [0, 2, 6, 20]
for I in I_values:
    print(f"I={I:5.1f}: competitive KM_app={KM * (1 + I / Ki):5.2f}, Vmax_app={Vmax:5.2f}"
          f"  |  non-competitive KM_app={KM:5.2f}, Vmax_app={Vmax / (1 + I / Ki):5.2f}")
# Hill function: activation (rising sigmoid) and repression (falling sigmoid)
def hill_activation(S, n, K=KM):
    return Vmax * S**n / (K**n + S**n)

def hill_repression(S, n, K=KM):
    return Vmax * K**n / (K**n + S**n)

n_values = [1, 2, 4, 8]
fig, axes = plt.subplots(2, 2, figsize=(11, 9))
for I in I_values:
    axes[0, 0].plot(S, v_competitive(S, I), label=f"I={I}")
axes[0, 0].set_title("Competitive inhibition")
axes[0, 0].legend()

for I in I_values:
    axes[0, 1].plot(S, v_noncompetitive(S, I), label=f"I={I}")
axes[0, 1].set_title("Non-competitive inhibition")
axes[0, 1].legend()

for n in n_values:
    axes[1, 0].plot(S, hill_activation(S, n), label=f"n={n}")
axes[1, 0].set_title("Hill activation (soft switch ON)")
axes[1, 0].legend()

for n in n_values:
    axes[1, 1].plot(S, hill_repression(S, n), label=f"n={n}")
axes[1, 1].set_title("Hill repression (soft switch OFF)")
axes[1, 1].legend()

for ax in axes.flat:
    ax.set_xlabel("[S]")
    ax.set_ylabel("v")
    ax.grid(alpha=0.3)
plt.tight_layout()
plt.show()

Fitting a Hill Function to Data

Everything above went forward: pick \(V_{max}\), \(K\), \(n\), then draw the curve. In the lab you go backward: you measure \(v\) at several \([S]\) and ask which \(V_{max}\), \(K\) and \(n\) produced it. Hill himself treated his equation as “a convenient curve for fitting”, so \(n\) is an empirical sharpness number, not a count of binding sites.

Below, synthetic “measurements” are generated from a cooperative curve with \(V_{max}=10\), \(K=5\), \(n=2.5\) plus Gaussian noise (fixed seed, so every run is identical). scipy.optimize.curve_fit recovers the parameters and their standard errors; we then fit the same data with \(n\) forced to 1 (plain Michaelis-Menten) to see what the extra parameter buys.

from scipy.optimize import curve_fit

def hill(S, Vmax, K, n):
    return Vmax * S**n / (K**n + S**n)

def fit_report(S_data, v_data, label):
    """Fit free-n Hill and n=1 (Michaelis-Menten); print parameters, 95% CI on n, and SSE."""
    p, cov = curve_fit(hill, S_data, v_data, p0=[8, 4, 1.5], bounds=([0, 0, 0.1], [np.inf, np.inf, 10]))
    se = np.sqrt(np.diag(cov))
    sse = np.sum((v_data - hill(S_data, *p))**2)
    p1, _ = curve_fit(lambda S, V, K: hill(S, V, K, 1), S_data, v_data, p0=[8, 4])
    sse1 = np.sum((v_data - hill(S_data, p1[0], p1[1], 1))**2)
    print(f"{label}")
    print(f"  Hill fit : Vmax = {p[0]:.2f} +/- {se[0]:.2f}, K = {p[1]:.2f} +/- {se[1]:.2f}, "
          f"n = {p[2]:.2f} +/- {se[2]:.2f}  (95% CI for n: {p[2]-1.96*se[2]:.2f} to {p[2]+1.96*se[2]:.2f})  SSE = {sse:.2f}")
    print(f"  n fixed 1: Vmax = {p1[0]:.2f}, K = {p1[1]:.2f}  SSE = {sse1:.2f}")
    return p, p1

# synthetic measurements: true Vmax = 10, K = 5, n = 2.5, noise sd = 0.4
S_data = np.array([0.5, 1, 2, 3, 5, 8, 12, 20, 35, 50])
rng = np.random.default_rng(0)
v_data = hill(S_data, 10, 5, 2.5) + rng.normal(0, 0.4, S_data.size)

p_hill, p_mm = fit_report(S_data, v_data, "Dataset A (true n = 2.5)")

fig, ax = plt.subplots(figsize=(6, 4))
ax.plot(S, hill(S, 10, 5, 2.5), "k:", label="true curve")
ax.plot(S_data, v_data, "o", label="noisy data")
ax.plot(S, hill(S, *p_hill), label=f"Hill fit, n = {p_hill[2]:.2f}")
ax.plot(S, hill(S, p_mm[0], p_mm[1], 1), "--", label="Michaelis-Menten fit (n = 1)")
ax.set_xlabel("[S]")
ax.set_ylabel("v")
ax.set_title("Fitting a Hill function")
ax.legend()
ax.grid(alpha=0.3)
plt.show()

The free fit lands near the true \(n=2.5\) with a confidence interval that excludes 1, and its sum of squared errors (SSE) is far below the \(n=1\) fit’s: the data really are cooperative. Two cautions: fitted \(n\) is usually below the number of binding sites (cooperativity is partial; haemoglobin has 4 sites but \(n\approx 2.8\)), and a fit can only report how sharp the data are, not why.

Discussion Questions

  1. Why does competitive inhibition become negligible at very high \([S]\), but non-competitive inhibition does not?
  2. Biologically, what kind of binding process would give a Hill coefficient \(n > 1\)?
  3. Why is a sigmoidal (“soft switch”) response often more useful for a cell than a purely hyperbolic Michaelis-Menten response?
